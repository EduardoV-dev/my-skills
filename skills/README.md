# First-party skills

Create one directory per maintained skill here, for example `skills/ev-my-skill/SKILL.md`.
Use the `ev-` prefix and match the directory name to the frontmatter `name`. Add optional `assets/`
or `references/` directories only when the skill needs them.

Use [project setup](../README.md#wire-skills-into-a-project) to wire installed skills into a project's
`AGENTS.md` for automatic session/task selection, including non-coding skills.
For global pre-coding standards and check/fix/update/add-rule workflows, use the
[global setup](../README.md#global-coding-standards). For standalone reviews, install `ev-code-review`
and the `ev-review-*` companions your project needs. See [review installation](../README.md#install-review-skills).
